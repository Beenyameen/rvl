# rvl

A monorepo containing fast implementations of the RVL algorithm, a lossless compression technique designed for 16-bit depth images.

## Installation

**[C# / .NET](https://www.nuget.org/packages/rvl/):**
```bash
dotnet add package rvl
```

**[Python](https://pypi.org/project/rvl/):**
```bash
pip install rvl
```
